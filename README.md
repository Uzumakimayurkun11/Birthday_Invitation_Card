# Maya's birthday invitation

A playful, responsive birthday invitation based on the Figma mobile design. The page includes a 5 × 7 inch print layout.

## Run it

Open `index.html` in a browser. No build tools or package installation are needed.

## Print or save as PDF

Select **Print or save as PDF** below the invitation. The print stylesheet sets the page to 5 × 7 inches. In the print dialog, enable **Background graphics** to preserve the gradient and confetti colors.

The RSVP button currently points to the reply deadline on the card. Add the host's preferred RSVP email or link before using it for a real event.
